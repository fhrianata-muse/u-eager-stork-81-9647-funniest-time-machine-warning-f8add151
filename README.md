One line, 100 characters — the funniest warning label for a time machine:

> WARNING: Do not leave luggage unattended. In 200 years it will be a museum exhibit, and so will you.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–120 character, single-line gate checks out at run time.
